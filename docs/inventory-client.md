# Inventory Client (ComposeApp)

## Цель
Маркировка встроена в существующую inventory-платформу и использует тот же `MeshNode` контракт, без отдельной подсистемы и без изменения messenger stack (чаты, группы, треды, файлы, звонки, routing/relay/discovery/diagnostics).

## UI-сценарии маркировки

### 1. Карточка объекта (`InventoryItemScreen`)
Раздел **«Маркировка»** показывает и управляет:
- активным штрихкодом (Code128) и QR;
- статусом кода, автором и временем выпуска;
- историей кодов (активные/неактивные);
- превью этикетки;
- историей печати;
- историей сканирования.

Действия в карточке:
- `Сгенерировать штрихкод` / `Сгенерировать QR`;
- `Перевыпустить`;
- `Деактивировать`;
- `Показать штрихкод` / `Показать QR`;
- `Открыть превью`;
- `Сформировать PDF`;
- `Печать`;
- `Скачать PDF`;
- `Поделиться`.

### 2. Печать из списка объектов (`InventoryScreen`, секция «Оборудование»)
Встроенный блок **«Печать маркировки»**:
- выбор шаблона (`Короткий`, `Стандартный`, `Расширенный`);
- выбор полей этикетки;
- включение/выключение Barcode/QR;
- выбор нескольких объектов;
- пакетная печать;
- просмотр последних задач печати + `Скачать PDF` / `Поделиться`.

### 3. Печать из сессии (`InventorySessionScreen`)
Блок **«Печать маркировки»** в деталях сессии:
- печать по объектам текущей сессии;
- те же настройки шаблона/полей/Barcode/QR;
- пакетная печать для комиссии;
- доступ к истории задач печати и PDF-артефактам.

### 4. Экран сканирования (`InventoryScannerScreen`)
Экран **«Сканировать»** поддерживает:
- сканирование камерой (inline scanner на поддерживаемых платформах);
- fallback системного сканера;
- ручной ввод QR/штрихкода;
- поиск по `resolveScannedCode`;
- экран результата со статусом (`Объект найден`, `Код неактивен`, `Не найдено`, и т.д.).

После успешного сканирования доступны быстрые действия:
- `Открыть объект`;
- `Отметить проверку`;
- `Обсуждение`;
- `Добавить фото`;
- `Добавить комментарий`.

## Mobile/Desktop

### Mobile
- inline camera scanner;
- крупные превью QR/Barcode;
- короткий flow для полевых проверок (скан -> действие).

### Desktop
- пакетная печать из списков и сессий;
- расширенный выбор объектов/полей;
- сохранение и шаринг PDF-пакетов.

## Контрактные вызовы из UI
UI использует только `MeshNode` API:
- коды: `generateInventoryCode`, `regenerateInventoryCode`, `deactivateInventoryCode`, `inventoryCodes`;
- шаблоны/этикетки: `inventoryLabelTemplates`, `generateInventoryLabelPreview`, `generateInventoryLabelPdf`, `printInventoryLabel`, `printInventoryLabelsBatch`, `inventoryPrintTasks`;
- сканирование: `resolveScannedCode`, `registerScanEvent`;
- workflow после скана: комментарии/вложения/переход в обсуждение через существующие inventory + chat операции.

## Язык UI
Все новые надписи для маркировки сделаны на русском и в коротких формулировках (`Маркировка`, `Печать`, `Сканировать`, `Не найдено`, `Объект найден`, `Скачать PDF`, `Поделиться`).
